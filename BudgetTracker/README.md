# Курсовая работа «Приложение для отслеживания бюджета»

Веб-приложение для ведения личного бюджета в рублях. Пользователь регистрируется, записывает доходы и расходы, редактирует и удаляет операции. За выбранный месяц отображаются доходы, расходы, их разница и распределение расходов по категориям. Фильтр журнала по типу операции не влияет на общую сводку.

## Запуск

Понадобятся .NET SDK 10, Node.js 22.12+ и npm. Из папки `BudgetTracker` выполните в первом терминале:

```sh
dotnet run --project BudgetApi --launch-profile http
```

Во втором терминале:

```sh
cd frontend
npm ci
npm run dev
```

Откройте [приложение](http://localhost:5173), зарегистрируйте аккаунт и добавьте первую операцию. Swagger доступен по адресу [localhost:5065/swagger](http://localhost:5065/swagger). При первом запуске API создаёт файл `BudgetApi/budget.db`. В режиме разработки ключ JWT по умолчанию генерируется при старте API, поэтому после его перезапуска потребуется войти снова. Для постоянного ключа задайте переменную окружения `Jwt__Key` длиной не менее 32 байт.

## Анализ образца Valera

| Часть образца | Назначение в Valera | Реализация в курсовой |
| --- | --- | --- |
| `Program.cs`, `appsettings.json`, `Properties` | Подключение контроллеров, SQLite, JWT, Swagger, CORS и профилей запуска | Та же схема запуска с отдельным портом и файлом БД |
| `Controllers` | Регистрация, вход, управление персонажами и игровые действия | Регистрация, вход, чтение, создание, изменение и удаление операций |
| `Services` | Интерфейс и реализация игровой логики, проверка владельца | Сервис операций с выборкой по владельцу и месяцу |
| `Models`, `DTOs` | Модели пользователя и персонажа, контракты запросов и ответов | Пользователь, финансовая операция и отдельные контракты для API |
| `Data`, `Migrations` | EF Core, схема SQLite и миграции, в том числе добавление владельцев | EF Core и SQLite с отдельной схемой бюджета |
| `frontend` | React и Vite, формы входа, API-клиент, список персонажей и показатели | Формы входа и операций, журнал, месячная сводка и расходы по категориям |
| `ValeraApi.Tests` | Проверки игровой модели | Для бюджета применимы сценарии проверки сумм, месячного отбора и доступа к данным |
| `bin`, `obj`, файл БД | Результаты сборки и данные экземпляра | Создаются локально при сборке и запуске |

В образце администратор может читать данные нескольких пользователей. Для личного бюджета все финансовые маршруты ограничены владельцем. API получает идентификатор владельца из JWT и проверяет его при каждом обращении к записи.

## Архитектура и модель данных

React отправляет HTTP-запросы с JSON в ASP.NET Core Web API. Контроллеры проверяют входные данные и вызывают сервис. Сервис работает с SQLite через EF Core. React считает сводку по полному списку операций выбранного месяца.

- `Users` хранит имя, уникальную электронную почту и хеш пароля.
- `Transactions` хранит владельца, тип, сумму, дату, категорию и комментарий. Связь с пользователем имеет тип «один ко многим».
- Суммы хранятся в целых копейках. Баланс за месяц равен сумме доходов за вычетом расходов за тот же месяц.

## Маршруты API

| Метод и путь | Действие |
| --- | --- |
| `POST /api/auth/register` | Зарегистрировать пользователя |
| `POST /api/auth/login` | Получить JWT |
| `GET /api/transactions?month=2026-11` | Получить свои операции за месяц |
| `GET /api/transactions/{id}` | Получить свою операцию |
| `POST /api/transactions` | Создать операцию |
| `PUT /api/transactions/{id}` | Изменить свою операцию |
| `DELETE /api/transactions/{id}` | Удалить свою операцию |

## Сценарий демонстрации

1. Зарегистрируйтесь и добавьте доход 50 000 ₽ и расход 1 250,50 ₽ за один месяц. Проверьте итог 48 749,50 ₽.
2. Измените расход на 1 000 ₽. Проверьте итог 49 000 ₽ и сумму в соответствующей категории.
3. Переключите месяц и вернитесь обратно. Проверьте, что журнал отображает записи выбранного месяца.
4. Войдите под другим аккаунтом. Его журнал должен быть пустым.
5. Войдите под исходным аккаунтом и удалите расход. Итог должен составить 50 000 ₽.

Команды сборки из `BudgetTracker`:

```sh
dotnet build BudgetApi
npm run build --prefix frontend
```
